# LocalLink 極簡滿版地圖執行計畫

日期：2026-10-11。狀態：A + B 介面已實作；驗證結果以交付紀錄為準。

## 1. 目標與範圍

採用 A 的暖灰低飽和地圖與開闊預設畫面，搭配 B 可展開的左側浮動列表。地圖填滿瀏覽器內容視窗的寬與高；搜尋、導覽、列表與操作按鈕均覆蓋於地圖上，不再占用獨立版面欄位。

本計畫取代既有文件中「地圖位於 header 下方」、固定側欄及明亮地圖配色的方向，限於地圖首頁。其他頁面的品牌樣式、資料模型、權限、API、圖層語意與功能旗標維持既有契約。示意圖僅供構圖參考，地理位置、範例內容、標誌與分類以實際產品為準。

相關背景：[地圖體驗指南](../guides/map-first-layer-experience-guide.md)、[既有視覺指南](../guides/ui-ux-modernization-guide.md)、[Jade Atlas](../design/jade-atlas-map.md)。上述文件包含歷史提案，實作應以原始碼與本計畫的明確變更為準。

## 2. 已確認的現況

- `map-workspace.tsx` 管理 URL 查詢、結果、選取、列表與圖層；Mapbox instance 已由 `map-canvas.tsx` 持續保留。
- `map.css` 目前用 grid 分割側欄、地圖與詳細內容，高度扣除 header；手機還扣除底部導覽。
- `navigation.tsx` 提供地圖 header；`map-toolbar.tsx` 透過 portal 將搜尋放到 `map-header-search`。
- 桌面側欄目前預設展開，並讀取 `taiwanhub.map.sidebar-collapsed`；手機 sheet 預設 `half`。
- `map-appearance.ts` 已在 Mapbox `light-v11` 上套用 Jade Atlas，隱藏部分底圖標籤；可延伸既有方法，不必更換地圖供應商。
- 現有地圖含插畫標記與選取 companion 裝飾，並非單純圓點；極簡版本需明確調整其呈現。
- `tests/e2e/map.spec.ts` 有 URL、列表、圖層、搜尋與 fallback 測試；部分案例假設列表預設可見，需隨新互動更新。

此為原始碼檢查結果，尚未進行執行中瀏覽器的視覺驗證。

## 3. 版面與視覺規格

### 桌面（大於 800px）

- 地圖容器寬 `100%`、高 `100dvh`，提供 `100vh` fallback；移除地圖首頁的 header、側欄、footer 版面占位與最小高度造成的頁面捲動。
- 左上：小型品牌／城市選擇、搜尋框與精簡篩選入口，外距 24px。主要分類沿用 domain 與旗標，不新增示意圖中的虛構分類。
- 日期、搜尋範圍等次要選项放入浮動 disclosure，已套用條件需有可見摘要與清除入口。
- 右上：圖層與帳號入口。圖層管理、收藏、語言、城市切換、About 等既有功能仍可到達；將原側欄導覽整合至有標籤的浮動選單。
- 左下：`顯示列表 · N` 浮動按鈕。N 使用目前查詢的結果總數，不以已載入頁數或地圖圓點數取代。
- 列表展開時置於左側搜尋區下方，目標寬 360px（可在 320–380px 間隨視窗調整），與邊緣保留間距；內部捲動，底部避開狀態訊息與 attribution。
- 右下：定位、縮放；保留供應商 attribution，不被其他面板遮住。
- 不保留收合後的固定 icon rail；列表開關不改變 canvas 尺寸。

### 手機（800px 以下）

- 相同滿版地圖，外距 12px 加 safe-area inset。頂部搜尋與帳號控制可換行，不擠壓輸入欄位。
- 列表預設縮成底部浮動入口；展開使用既有 sheet 的半高／展開狀態，四周有間距與圓角。
- 提供明確展開、縮小、關閉按鈕，不要求拖曳才能操作。
- 底部導覽改成精簡浮動入口；sheet 展開時避免與導覽、定位和 attribution 重疊。
- 軟鍵盤開啟、橫向與短視窗時面板可捲動；空間不足改用單一內容面板，不疊出無法操作的控制。

### 色彩與元件

下列為起始 token，實作時以瀏覽器對比檢查微調；只作用於地圖首頁。

| 用途           | 起始值               |
| -------------- | -------------------- |
| 地面           | `#F2F0EA` 暖灰       |
| 道路／邊界     | `#FAF9F6`／`#D8D6D0` |
| 公園           | `#DEE5D8` 灰綠       |
| 水域           | `#CDDDE0` 灰藍       |
| 浮動表面       | `#FFFEFB`            |
| 主文字／次文字 | `#28332F`／`#59645F` |
| 選取與主要操作 | `#45695B`            |

- 面板圓角 16px，控制圓角 12px，細邊框與輕陰影；不加入大面積玻璃效果或強烈動態。
- 低對比用於底圖；文字、控制邊界與焦點保持足夠辨識度。一般文字目標 4.5:1，必要 UI 圖形與焦點目標 3:1。
- 標記以小圓點為主，選取使用外框與簡短標籤；保留群聚與至少 44px 點擊範圍。類型在列表和選取標籤中以圖示／文字補足，不能只靠顏色。
- 地圖首頁停用插畫 sprite 與 companion 選取裝飾，保留資料選取與必要提示；不刪除其他功能可能共用的裝飾程式。
- 外部搜尋結果仍須与本地項目可區分。縮遠時降低標籤密度，縮近才增加道路細節。

## 4. 互動與狀態規則

| 情境                                | 預期行為                                                             |
| ----------------------------------- | -------------------------------------------------------------------- |
| 首次進入可用地圖                    | A：列表收合，顯示結果入口                                            |
| 點顯示列表                          | B：展開結果；鏡頭、篩選與選取保留                                    |
| 點圖層                              | 在同一左側面板顯示圖層，避免與列表相互遮蓋                           |
| 提交搜尋                            | 顯示結果面板；保持目前搜尋 scope 語意                                |
| 點標記／結果／開啟含 item 的 URL    | 在同一浮動面板顯示詳細內容；保留返回結果入口                         |
| 關閉詳細內容                        | 清除 item 狀態，返回原列表／圖層與捲動位置；Back/Forward 與 URL 同步 |
| 收合面板                            | 不清除已選取項目或篩選；重新開啟恢復原內容                           |
| 明確 `view=list` 或已記住純列表偏好 | 尊重既有選擇，提供完整可捲動列表，不強制回到 A                       |
| Token 缺少、WebGL 或供應商失敗      | 自動提供可見且可操作的列表與原因／重試；不可只剩空白地圖與隱藏列表   |
| 無結果／無座標／線上項目            | 顯示既有空狀態與位置說明，列表仍能找到無地圖座標項目                 |

列表開關屬 UI 狀態，不新增公共 URL 參數。沿用既有桌面收合儲存 key：無紀錄預設收合，有紀錄尊重舊偏好；storage 不可用時仍能正常操作。手機預設 peek，同次使用中保留展開程度。分享連結的 item 與 fallback 優先於收合偏好。

面板採非模態區域；收合時隱藏內容不進入 Tab 順序。以 Escape 關閉最上層選單或目前面板，焦點回到啟動按鈕；與輸入控制的 Escape 行為協調。中英文字典都補齊按鈕、狀態與 aria 文案。動畫約 150–200ms，尊重 reduced motion。

## 5. 分階段實作

### 第一階段：建立滿版與浮動骨架

涉及 `apps/web/src/components/navigation.tsx`、`apps/web/src/components/map/map-toolbar.tsx`、`apps/web/src/components/map/map-workspace.tsx`、`apps/web/src/app/map.css`，必要時調整 `layout.tsx` 的地圖專用整合。

1. 實作前閱讀 `apps/web/AGENTS.md` 與安裝版 Next.js 中相關 layout／CSS 文件。
2. 限定地圖首頁的 shell，避免全站 header/footer 或捲動受到影響。
3. 移除 grid 占位；建立 canvas 底層、浮動控制層、popover 層的明確疊放順序。控制層空白區不得攔截地圖拖曳。
4. 調整搜尋 portal 的掛載位置，確保 SSR/hydration 時只有一份可操作搜尋與穩定布局。

驗收：地圖貼齊四邊、無額外頁面捲軸；非地圖頁導覽正常；全部既有入口可到達。

### 第二階段：整合浮動面板與手機 sheet

涉及 workspace、`map-results.tsx`、`active-layers-panel.tsx`、`item-preview.tsx`、外部商家面板與 `apps/web/src/lib/dictionary.ts`。

1. 統一結果／圖層／詳細內容的面板狀態，移除桌面 detail rail 占位；保留 URL 查詢與載入控制。
2. 套用上述開關、搜尋、深連結、焦點、偏好與 fallback 規則。
3. 列表改為精簡列，保留名稱、類型、活動日期、demo／私有標示及重要狀態；圖片不再主導，詳細內容仍可顯示原照片。
4. 保留 Daily Pick、外部商家發現、載入更多、錯誤重試及各旗標下的入口，放入適當面板內容。
5. 依面板與控制的實際尺寸計算 map padding；所有選取、fitBounds、外部搜尋定位與地理定位使用同一可見區域規則，避免目標藏在面板後。

驗收：面板開關不重建 Mapbox instance、不重設查詢；桌面與手機均能搜尋、選取、返回、切換圖層及使用純列表。

### 第三階段：底圖與標記簡化

涉及 `apps/web/src/lib/map-appearance.ts`、`apps/web/src/components/map/map-canvas.tsx`、map CSS 及必要的標記裝飾掛載處。

1. 在既有 light-v11 的 restyle 路徑調整暖灰色盤與標籤密度；保留道路與地理資料的正確性及語言 fallback。
2. 使用簡潔標記、群聚、hover／selected 狀態，停止在此畫面掛載插畫與 companion。
3. 不以 CSS filter 降低整個 canvas 飽和度，以免連同互動標記的辨識度一起降低。
4. 若變更 Mapbox API 用法，先核對安裝 SDK types 與官方文件；不新增供應商、金鑰或依賴。

驗收：接近 A 的暖灰低飽和感；一般、選取、群聚、外部結果清楚可辨，圖層與座標保持正確。

### 第四階段：回歸驗證與交付

- 執行 `pnpm lint`、`pnpm typecheck`、受影響單元測試與 `pnpm build`。
- 更新 `tests/unit/map-appearance.test.ts`；若提取面板狀態／padding 純函式，測試有行為意義的狀態轉換與邊界。
- 更新並執行 `pnpm exec playwright test tests/e2e/map.spec.ts`。案例先明確開啟列表，不再依賴舊預設。
- 新增首次收合、儲存偏好、開關不改 canvas bounds、深連結／Back、搜尋自動展開、fallback 自動可見、手機 sheet 與鍵盤焦點回歸。
- E2E 前確認有效 `DATABASE_URL` 指向可丟棄的測試資料庫，且共用伺服器使用同一資料庫；不得印出憑證。現有測試可能寫入 fixtures。
- 在 1440×900、1024×768、390×844、手機橫向與 200% 縮放下檢查；涵蓋英文／繁中、長標題、登入／未登入、旗標及 reduced motion。
- 無 token 的 CI 可驗證 fallback，不能作為真實底圖通過的證據；以有效開發 token 額外驗證色彩、群聚、實際點擊與 attribution。缺少環境時明確記錄未驗證項目。
- UI 範圍不預期更動 persistence／授權；若實作超出此範圍，補跑相關 integration tests。
- 更新地圖體驗指南與 Jade Atlas 文件，標明已實作的新行為；審查 diff 後只提交本次檔案，建立本地 commit。部署與 push 另行授權。

## 6. 完成標準

使用者首次進入看到 A；主動開啟列表後看到 B。兩者共享同一張滿版地圖、同一組搜尋與圖層狀態。任何視窗大小、列表或詳細內容狀態下，主要操作與必要 attribution 均可使用；無地圖時仍有完整探索流程。驗證結果、阻擋項目與桌面／手機截圖隨實作交付。
