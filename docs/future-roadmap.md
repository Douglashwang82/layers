# Future roadmap

Before public Houston beta: replace demo records with verified local data, configure email verification/recovery and object storage, validate provider integrations, establish moderation ownership, and review accessibility with real users.

After local density is established: add city-localized headings and event-time presentation, improve search with measured PostgreSQL indexes, introduce signed upload URLs when traffic warrants, add a scheduled event-data refresh process, and measure activation/retention cohorts from existing analytics.

Next app boundary: Expo consuming `/api/v1`, shared Zod/types and Better Auth bearer credentials stored securely. Keep public web SEO and native navigation separate.

Later product work, not implemented in v0.1: organization/business claims, partner administration/analytics, notifications, sponsored listings kept separate from scores, services, affiliate commerce and tickets. Do not add chat, DMs, forums, dating, housing, jobs, payments, real-time inventory, ordering, loyalty, AI chatbot or ML recommendations without a new product decision.
